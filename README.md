A deterministic TypeScript program that writes one original two-line family scene — at most 280 characters — to `/output/entry.txt`.

The scene: *"Dad spent all afternoon fixing the wobbly kitchen table. At dinner he tapped it once, grinned at all of us, and said, 'One screw. Thirty years. Worth it.' Mom raised her glass to the table."* (189 characters)

## Run it

```sh
node main.ts
```
